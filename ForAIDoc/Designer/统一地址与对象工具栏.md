# 统一地址栏与对象操作

工作台顶部使用两行：地址行 + 分组工具栏。原 Files 页的重复地址栏与工具条移除，右键菜单保留。900px 以下自动切为带名称提示的图标工具栏，仍支持横向滚动；复制、粘贴始终在地址行右侧。

## 地址规则

- 输入相对工作区路径、绝对本地路径或具体 depot 路径，Enter 跳转。
- 粘贴按钮与地址框内 Ctrl/Cmd+V 使用同一清理函数：移除首尾空白/BOM/零宽空白和成对引号；解析 file URL；保留文件名内部空格与 Unicode。
- 拒绝多行、控制字符、网页协议，以及带通配符/修订选择器的 depot 地址。不执行文本，不猜测多个地址中的哪一个。
- 复制当前对象的规范地址，不复制尚未成功跳转的输入草稿。已有本地文件优先显示本地地址。
- 文件跳转打开 Files 并定位选中项，必要时清除隐藏它的筛选；目录跳转显示其子项。Escape 放弃输入。新选择或新输入使旧异步跳转结果失效。
- 目录查询缓存按连接和目录隔离，侧栏/列表/定位复用请求；路径映射缓存 60 秒。无剪贴板轮询。

## 焦点与操作

操作对象不是 DOM 输入焦点。点击地址栏或工具按钮保持对象；切换页签后重新绑定对象。文件专属页签使用自己的参数，锁定页签不会误用其他文件的选择。全局页面清除文件操作对象。

| 对象 | 可用操作 |
| --- | --- |
| 未跟踪文件 | 添加、本地预览、系统定位、其他软件打开 |
| 已受控文件 | 获取最新、签出、标记删除、Diff、History、Revgraph、预览与系统操作 |
| 已签出文件 | 还原及适用的查看操作；禁止重复签出 |
| 冲突文件 | Diff、History、Revgraph、还原及可用的本地查看；禁用直接更新/删除 |
| 未同步的 depot 文件 | 获取最新、History、Revgraph；本地预览/系统打开禁用 |
| 目录 | 浏览、刷新、获取最新/指定版本、递归签出/标记删除/还原；本地目录可扫描添加未跟踪文件、系统定位 |
| 非空、已编号的待提交 CL | 提交整个 CL，确认框明确显示编号与文件数量 |
| Default CL、空 CL、已提交 CL、设置等全局对象 | 不允许直接提交或误用上一次文件的修改操作 |

精确状态矩阵集中在 `src/app/shell/commandPolicy.ts`。禁用按钮保留位置，悬停显示原因；可用按钮保持正常对比度，主要查看/同步入口使用强调色。

- 删除/还原/提交需要确认。还原提示丢失未提交修改。
- 多选修改及任何目录修改也必须确认，展示目标列表与递归范围。目录使用 `...` 文件规格，由 P4 判断子文件是否适用；目录本身的显示状态不是子文件状态汇总，操作可能部分成功，取消不回滚。
- 目录添加使用 `reconcile -a`，只添加未跟踪文件并遵循 P4IGNORE，不顺带签出或删除。目录删除仅标记受控文件，不把整个本地目录移入垃圾桶。参见 [Perforce reconcile](https://help.perforce.com/helix-core/server-apps/cmdref/current/Content/CmdRef/p4_reconcile.html)。
- 文件夹不启用单文件预览、Diff、History、Revgraph 和“其他软件打开”；文件夹历史/目录差异需另做聚合界面。提交仍以 CL 为单位，不把所选文件夹隐式提交。
- 刷新针对文件和待提交列表，不自动 sync；文件专属页保留自身的刷新按钮。

### 文件路径型页签头

Diff、Rev Graph、History 和文件预览统一为一行：页签类型、跟随/锁定、路径框、框外“新页签”。刷新使用路径框最右端的纯图标按钮，由原页面通过刷新 slot 提供回调及 loading/disabled 状态；保留 title、aria-label、键盘焦点和 28px 点击热区，路径文字与按钮分占 flex 空间，不能重叠。

History 删除重复标题/说明、头部“配置 Swarm”及第二条路径输入/“查看历史”，保留搜索、记录数、版本比较和表格。Swarm 业务及其他菜单入口保留。文件预览同样移除重复头部与第二条路径输入，保留文本/图片工具、缩放、模拟提示和内容。History/预览的路径仍直接提交原输入，不新增路径映射请求；Diff/Rev Graph 保留既有路径规范化行为。Streams 不属于路径型页签。

所有实际可多开的页签（History、Diff、Rev Graph、文件预览、Shelf）统一使用纯图标的锁、新页签和刷新按钮，沿用原生 `title` 悬停提示，并提供一致的 `aria-label`。锁按钮提示当前“正在跟随文件选择；点击锁定当前目标”或“目标已锁定；点击恢复跟随文件选择”，保留 `aria-pressed`。新页签提示“新页签”，刷新提示“刷新”；中英文随界面切换。锁/新页签保留 32px 点击热区与可见键盘焦点。Shelf 保留只读目标框和独有详情、取消及 Swarm 操作，刷新放在其目标框内最右端；不把 Shelf 目标改成可编辑文件路径。
- 执行期间仍能切换页面；修改按钮暂时禁用。取消只作用于当前工具栏启动的 P4 任务，不取消终端或其他窗口任务，取消不代表回滚已完成的修改。

## 平台边界

- 浏览器演示不读取真实本地文件，也不启动系统应用；系统按钮禁用并说明原因。
- 桌面剪贴板使用 Tauri clipboard-manager，仅启用文本读/写权限；只有用户点击粘贴才读取，不记录内容。[官方接口说明](https://v2.tauri.app/plugin/clipboard/)。
- macOS 定位使用 Finder；其他软件打开先选择应用，再把文件作为独立参数交给应用。
- Windows 使用 Explorer 定位与系统 [Open With](https://learn.microsoft.com/windows/win32/api/shlobj_core/nf-shlobj_core-shopenwithdialog) 对话框。
- 系统打开仅接受当前工作区内真实存在的规范化本地路径，拒绝越界与符号链接逃逸，不接受可执行文件或命令行参数作为接口输入。

## 代码边界与验证

### 统一多选

- Depot、工作区侧栏、Files 共用一个选择集合。普通点击替换，Ctrl（Windows）/Cmd（macOS）点击增减，Shift 点击连续范围，Ctrl/Cmd+A 选择当前筛选结果全部项目（包括虚拟列表未渲染项），Escape 清空。
- 选中按 depot / 本地路径识别，不依赖各来源的临时 ID；每个列表独立维护范围选择锚点。右键已选项保留整组选择，右键未选项改为单选。
- 多选时地址栏显示主目标，同时显示文件/目录数量；未锁定的查看页签跟随主目标，参数跟随不会清空多选。
- 批量工具检查整组选中对象，不静默忽略不适用项；选中父目录与子项时合并覆盖范围。查看工具、系统定位和其他软件打开暂限单选。
- `selection.ts` / `SelectionContext.tsx` 负责选择语义；`selectionCommands.ts` 负责去重与安全文件规格；工具栏及 Files 右键菜单复用同一执行入口。
- `resolveSelection.ts` 按父目录批量补全 Depot 的本地状态，共享查询缓存，最多四个并发目录查询，不随文件数逐条请求 P4。

- `address.ts`：纯文本清理；`resolveAddress.ts`：缓存与对象解析。
- `useCommandTarget.ts`：页签/对象焦点及过期异步结果隔离。
- `commandPolicy.ts`：纯能力判断；`CommandBar.tsx`：地址与工具交互。
- `system_open.rs`：受限的系统打开；`infrastructure/clipboard.ts`：桌面/浏览器剪贴板适配。

自动化覆盖路径清理、查询去重、目录/文件状态矩阵、系统路径边界。浏览器验证粘贴跳转、文件选中、全局页面禁用行为。macOS Rust 编译测试通过不等于两平台原生交互验收，Finder/应用选择器和 Windows 原生对话框仍需在桌面版实际验证。


## 固定页签头

注册表中 scope 为 global 的 11 个固定页签统一沿用 Pending 的紧凑标题栏（图标、14px 标题、右侧页面操作），不显示文件目标框、跟随锁或新页签按钮。Files、Search、Workspace、Streams、Stream Graph、Branch Mappings、Settings 移除内部重复大标题和眉题；原说明保留在可用键盘展开的信息提示中。目录名、计数、搜索数据模式和刷新/创建操作保留；Terminal/P4 Log 的工具视图切换移入标题工具区，独立抽屉保持原布局。各页过滤器与正文不变，多开页签沿用原有图标头部。


## History 表格

History 固定列序为版本号/CL号、时间、提交人、描述。时间使用已加载的 FileRevision.time，始终显示年、月、日及小时/分钟，跟随界面中英文并保持本机时区；缺失或无效时间显示“—”。不再显示 History 右侧详情区，选择、范围多选与版本比较保留。

列边界沿用 Pending 的 pointer capture 拖动方式，支持方向键和 Home；最小宽度分别为 140/190/100/180px，时间列默认 210px，完整格式化时间也显示在悬停提示中。列宽仅保存在当前页签状态，不新增持久化。描述默认单行省略，按实际元素溢出或换行判定展开按钮；ResizeObserver 在列宽变化后重新判断。每条记录独立展开，完整描述紧随原行跨列展示，保留换行并允许长串换行；展开不触发行选择或重新请求差异。虚拟行动态测高，不使用固定高度覆盖展开内容。


History 的比较统一使用顶部工具栏“差异”，不再显示独立比较按钮或内嵌差异。激活的 History 页签向工具栏发布最多两个修订；其他隐藏页签不能覆盖目标。选择状态是容量为 2 的 FIFO 队列，按实际新增顺序记录，第三个不同版本入队时淘汰最早一条；点击已选行取消。普通/Ctrl/Cmd/键盘/右键、Shift 范围和全选都通过同一队列更新，批量新增按显示顺序处理，已在队列中的项不重复入队。刷新移除失效项，切换文件清空选择。不显示选择数量限制的额外文字提示；Diff 左右版本排序不修改选择队列顺序。

历史比较携带明确的左右 revision 参数，旧版本在左、新版本在右，始终创建新的锁定 Diff 实例；普通工作区文件的差异语义不变。页签标签和顶部标题共用 pageDefinitions/pageLabels 的现有语言键，切换语言即时刷新，保留文件名和用户数据。


History 行菜单使用独立 H01，仅列出预览 CL、获取这个版本、Undo、Diff，不影响 Rev Graph 菜单。预览 CL 指向右键行所属的已提交 CL；获取指向 FIFO 队列中后选的文件修订，复用 SyncDialog，固定 revision 并要求先预览、再确认。已选行右键不重排队列，未选行右键按 FIFO 入队；菜单标题与同步对话框明确显示目标。双选 Diff 使用这两个文件修订，新建锁定页签；单选 Diff 禁用并提示选择两个有效修订，不猜测上一版/工作区比较。

先选/后选分别使用蓝色/琥珀色背景，并通过行的 aria-label/title 说明顺序及获取目标。Undo 作用于右键行的单文件、单修订，打开专用预览/确认窗口，不重排 FIFO，也不扩大到双选区间或整个 CL。真实后端使用 `undo -n 文件#revision` 预览与 `undo 文件#revision` 执行，结果进入默认待提交列表，不自动提交；后续修订可能需要同步及 Resolve。连接代次、精确目标、预览内容与本地内容绑定到两分钟一次性令牌；确认前在修改队列锁内重新检查。已打开/有本地改动、移动配对、非单文件输出与无法完整核验的输出会明确拒绝，不能强制覆盖。浏览器 mock 不模拟成功。离线 `cargo check --offline --locked --lib` 已通过；Undo 参数、输出解析、令牌、通用入口拒绝与 runner 预览分类共 6 个纯 Rust 测试通过，测试未创建 P4 进程。前端交互测试及本地 fixture 集成尚未验收。

历史 Diff 的 comparison 必须从 Dock 参数经 PageRenderer 明确传给 FileReviewPage，再生成 RevisionReference；修订号是 #N，不是 @CL。回归覆盖实际 PageRenderer 到 fake backend 的请求，避免只测直接挂载 FileReviewPage 而漏掉中间参数转发。


## CL 详情弹窗

查看 CL 统一通过 ChangeDetailsContext/open 动作，复用 Dialog 和 RevisionFileList，不跳转 Submitted，不新建页签。覆盖 History 的预览 CL、Submitted 双击/Enter/右键查看详情、Pending 右键查看详情、搜索中的已提交/待提交 CL、Rev Graph 打开所属 CL，以及全局工具栏选中 CL 时的详情按钮。提交、Undo、Get 和 Shelf 内容操作保持原语义。

弹窗按元信息、完整多行描述、虚拟文件列表、关闭排列；只显示已有字段，不新增 Edit/Print/Jobs 操作。Submitted 复用 getSubmittedChangeDetail；Pending 优先显示明确标注的已加载列表快照，其他入口按现有分页查询读取。描述与文件列表可滚动，Esc/关闭返回原控件焦点；不修改原列表滚动位置或切换页签。Submitted 原内嵌详情读取/侧栏已移除，单击只选择，双击或 Enter 查看。

请求绑定连接 key、profile、context generation 与打开序号；连接切换立即卸载旧弹窗，取消旧操作并丢弃迟到结果。切换 CL 不重用旧数据，loading/error/retry/empty/partial 都有明确状态。新增 fake backend 回归覆盖目标、取消/焦点、乱序响应、连接切换及 Pending 快照；当前只做静态/类型检查，交互与实际本地 fixture 验收未运行。


Diff 版本栏与跳转组合统一使用局部 `--diff-control-height: 28px` 与 6px gap。左右版本栏共用三列网格，标签、下拉、数字输入居中；520px 以下统一改成标签独占一行、下拉/输入下一行。跳转组合使用同高三列网格；base-select 显式居中，保留原生下拉、数字输入与跳转回调。样式仅作用于 Diff，不修改全局表单或对话框。类型、格式、CSS 语法和布局规则静态检查通过；未启动应用进行像素验收。
