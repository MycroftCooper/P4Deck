# 右键菜单待实现清单

更新：2026-11-18。本文是**未接通菜单项的唯一去处**。

## 规则

菜单只列当前能执行的动作，不列功能清单。

- `phase: "initial"` 的条目属于已交付菜单：要么可执行，要么用具体原因说明"这个目标为什么用不了"（例如冲突未解决时禁用「解决」）。
- `phase: "later"` 的条目是 backlog。**没有任何页面绑定可执行动作时，它不会被渲染**——既不进子菜单，也不显示为灰项。
- 因此"点了全是未接通"这种体验在结构上不再出现；想知道还差什么，看本文或 `src/app/context-menu/catalog.ts` 里 `phase: "later"` 的条目。

证据：`src/app/context-menu/model.ts` 的 `buildMenu`；`src/app/context-menu/model.test.ts` 断言"later 且无绑定 ⇒ 不渲染""绑定后立即出现"。

开发验收页（`?menu-audit`）会把全部条目带上回调渲染，用于逐项核对清单本身，不代表生产菜单。
