# 文件角标系统

## 实现范围

统一组件 `src/features/files/components/FileStatusIcon.tsx`，纯状态转换 `src/features/files/fileDecorations.ts`。接入 Files、工作区/Depot 资源树、Pending 打开文件/Shelf 副本、Submitted 修订文件清单。文件夹不推测子项状态，不递归查询。

支持可组合的操作、我方/他方、同步、锁/全局锁/独占、Resolve、映射、流导入、占位、符号链接和查询状态。图标最多显示三个角标；超过时保留两个高优先级角标与 +N，title 和读屏标签始终包含完整说明。风险优先，其次 Shelf、操作、同步等。红色我方、蓝色他方、紫色 Shelf，配合符号和中英文说明。

## 数据边界

- 当前适配九种 FileState、revision/headRevision、Pending action、Depot headAction 和 Shelf 上下文。
- `openedEdit` 只表示签出，不推断内容修改；controlled 不推断已同步到最新。比较明确修订号才能显示最新/落后/未同步。
- Depot 的 UI 选择对象可能以 missing 占位，本组件按 depot scope 忽略这一工作区字段，不能显示假缺失。
- Shelf 的 action 属于搁置副本，不推断本地状态；历史修订不显示当前工作区同步情况。
- 他方、锁、映射、符号链接等通过可选 `badges` 事实输入支持；现有后端没提供时不显示，不为每行发请求。该输入仅是前端展示模型，不更改 IPC 契约。
- 此次不覆盖 Graph depot 专用 headBlob/headCommit 模型，不宣称已接入尚未提供的服务器状态。

## 验证

纯转换测试覆盖组合、去重、来源隔离和未知边界；组件测试覆盖溢出、完整可访问标签、中英文及无额外 Tab 停靠点。浏览器验证行内角标位置，避免旧列表宽泛 span 样式拉伸图标。
