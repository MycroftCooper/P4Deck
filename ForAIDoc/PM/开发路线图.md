## 当前里程碑：Windows 本机私用

此里程碑只回答一个问题：P4Deck 能否在**当前这台 Windows 机器上**由本人安全完成日常 P4 工作。它不要求公开发布、跨平台交付、企业部署或异机恢复。

实现基线已经具备：Tauri/React/Rust 工程、受控 P4 Runner、多 Profile 与 Workspace 切换、Workspace/Depot、Sync/Edit/Add/Delete/Revert/Rename、Pending/Submitted、Submit、Shelf/Unshelve/Resolve、文本手工合并、Diff/History/Revision Graph、Search、Stream 切换与 Stream Graph、Branch Mapping、Lock/Unlock、Log/Journal/Diagnostics，以及浏览器和 Windows localhost 自动化证据均已落地。当前不再以“补功能面”为主线。

当前执行顺序以 [Windows 本机私用 TODO](Windows本机私用TODO.md) 为唯一清单：

1. 用最新本地提交完成 Tauri 原生构建、启动和版本绑定。
2. 在隔离 fixture 上完成 Windows 原生窗口核心 UI 冒烟。
3. 连接本人实际 P4 Server，验证其真实认证方式和只读访问。
4. 只在 fixture 或本人专用测试 Depot/Workspace 执行核心写入安全演练。
5. 验证故障恢复、配置备份/回滚和连续 2 小时稳定性。
6. PM 核对证据并关闭阶段。

### 退出条件

- 最新 commit 的 Tauri Windows 构建能启动、正常退出，且证据记录生成物与 commit。
- 原生主窗口完成核心导航、设置/Profile、Workspace/Depot、Search、Pending/Submitted、Shelf/Submit/Resolve、Diff/History/Graph、Stream、Lock、Log/Journal/Diagnostics，以及 390px、dock/popout、命令面板/前端快捷键/焦点的人工冒烟；同时确认退役的 Connection/Changes/Navigate/View 顶栏菜单不再出现。
- 本人实际 Server 的 `info/login status`、Client/Workspace 映射和只读浏览通过；SSL/SSO/MFA 只在该 Server 实际要求时成为退出条件。
- mutation 仅在隔离 fixture 或本人专用测试数据上完成，执行前后有清单、服务器侧复核和清理证据；生产数据没有被用于故障注入或自动化。
- partial/unknown/cancelled、断网/认证失效、异常退出后的刷新与人工恢复路径通过，不发生自动重放。
- 应用配置和本地状态完成一次离线备份与恢复演练；凭据不进入仓库或普通备份。
- 当前机器连续运行至少 2 小时，无数据错误、崩溃或无法解释的 mutation；本阶段 P0/P1 均关闭，P2 收口记录完成。

## 历史里程碑

以下阶段用于解释实现演进，不是当前任务队列；完成状态以《项目状态总览》和自动化证据为准。

### 阶段 0：项目启动（已完成）

- 建立 Tauri、React、TypeScript、Rust 工程与基础 UI。
- 建立测试、文档、Windows 开发环境和本地 Git 基线。

### 阶段 1：最小完整链路（已完成约定实现）

- P4 CLI/Runner、连接/认证、多 Profile、Workspace 切换、日志与安全边界。
- 用户无需终端即可配置连接并进入 Workspace；真实本人 Server 仍由当前里程碑验收。

### 阶段 2：日常 Workspace 工作流（已完成约定实现）

- Workspace 状态、虚拟列表、Sync、基础文件操作、单文件 Rename/Move、Lock/Unlock、Diff 与 History。
- Windows localhost 已有真实应用层 E2E；原生 Windows 点击由当前里程碑验收。

### 阶段 3：Changelist 工作流（已完成约定实现）

- Pending/Submitted、文件移动、Submit、Shelf/Unshelve/Resolve、文本手工合并、稳定查询与操作记录。
- “修改到提交”的实现和隔离 fixture 闭环已经存在，不再写成“基础 Shelf 待开发”。

### 阶段 4：质量基础（已完成本机所需自动化部分）

- Search、基础 Stream 切换、Swarm 安全链接、诊断导出、本地化、键盘/ARIA、390px 浏览器布局、前后端本机性能基准和统一前端 action 完整性校验。本人验收后已移除重复且不符合设计的原生 Connection/Changes/Navigate/View 顶栏菜单；连接管理固定在 Settings，其他导航继续使用侧栏、页面、命令面板和前端快捷键。
- 自动化证据不等于 Tauri 原生窗口实机证据；当前里程碑专门补齐该边界。

## 后续发布/外部验收，不属于当前阶段

- Git remote、远端 CI 和异机恢复证明。
- macOS、Linux、Windows ARM64 与跨平台一致性。
- Windows/macOS 代码签名、公证、正式 installer、正式 updater 和公开发布流程。
- 企业 SSO/MFA；本人实际 Server 强制要求时除外。
- 第二 Server、Broker/Proxy、P4/P4D 多版本、Unicode/non-Unicode Server 兼容矩阵。
- 固定多设备性能认证、NVDA/VoiceOver 与双平台读屏认证。
- Label/Job 独立工作台、Stream spec 写入及其他 P2 产品功能。Stream Graph、Branch Mapping 与 Global Search Stream/Shelf 已由独立批次完成，不再列为待实现项；其 Windows Tauri/本人 Server 真实性验收仍属于当前里程碑。管理员 Force Unlock 已按用户决定从产品移除，管理员需要时在后台执行，不进入当前或后续 UI 路线图。
- 菜单台账中的 190 个 `phase: later` 项。

后续是否启动这些工作，由本人实际使用反馈或发布目标另行立项；它们不得反向阻塞当前 Windows 本机私用里程碑。
