# 手工文本三方合并工作流

日期：2026-10-09；最终复验：2026-10-10。范围：已有 `ResolveDialog` 内的文本内容冲突；不包含二进制/图片语义合并、symlink、delete/move、外部 mergetool 管理或 Stream Graph。

## 用户流程

1. `Inspect conflicts` 仍先读取真实 unresolved 状态。只有 Perforce 返回文本 content resolve、明确 base/source revision、普通 Workspace 文件且未超过 4 MiB/100,000 行时，才显示“打开安全手工合并”。
2. 编辑器展示 Base / Theirs / Yours / Result 四栏。Result 初始值由行级三方合并生成；冲突块有稳定标记、上一/下一导航和未解决计数。Accept Yours / Theirs / Both 只替换当前块，不按重复正文全局替换。Result 支持搜索、显式撤销/重做、原生文本编辑快捷键；720px 以下四栏纵向排列。
3. “验证待保存结果”只检查当前内存正文、大小/编码和未解决块，并签发一次性短期 save token；它不写文件。“确认原子保存”才覆盖 Workspace 文件。
4. 保存成功只表示编辑结果已落盘，不表示 Perforce 已 resolved。用户必须再勾选明确确认并点击“标记为已解决并复核”，后端才执行 `resolve -ay`（接受已经写入的 Workspace 结果），随后以 `resolve -n -o`/`fstat` 复核 unresolved 状态。

## 数据与安全边界

- 三方身份来自官方 `p4 resolve -n -o` tagged 字段：`resolveBaseFile/resolveBaseRev`、`resolveFromFile/resolveEndFromRev`、`resolveType`；兼容旧字段名但不以 have/head 猜 base。正文通过 `p4 print -q -o <受控临时文件> <明确 depot#rev>` materialize，避免正文进入 Runner Log/Journal。
- 会话绑定 active profile、Server/User/Client/Workspace、context generation、depot/local path、两侧明确 revision、resolve-record digest、文件 size/mtime/SHA-256、encoding/BOM/line ending。会话正文和 save payload 只在进程内存中短期保存，不进入 localStorage、通知、Log 或 Journal。
- save token 与 session/result digest/编码后 bytes 绑定，一次消费、默认 120 秒；确认后进入同 Server mutation lane，重新检查 profile/generation、resolve record、安全规范路径、普通文件、Workspace Root 和完整文件快照。外部改写、token 重放/错绑/过期或旧连接响应均拒绝。
- 写入使用同目录 `create_new` 临时文件、flush + `sync_all`、平台原子 replace；Windows 对 Perforce 只读目标仅在 replace 窗口暂时调整属性，失败恢复属性和原文件。replace 同时保留隐藏的唯一 backup，返回其路径供恢复；Journal 只记录 LocalFile operation 元数据和终态，不记录正文。
- resolve token 在已保存 SHA-256 复核后签发；resolve 前再次检查文件 snapshot 和 resolve record。成功、partial、unknown 都触发 Workspace/Pending/Search/Diff/History/Resolve 相关缓存刷新，unknown 不冒充成功。

## 阻断与降级

- binary、symlink/reparse 越界、delete/move、非 content resolve、缺 base/source revision、不可识别编码、超过 4 MiB/100,000 行、路径不在当前 Workspace Root、文件或 resolve record 漂移：不开放手工编辑，保留原有 Safe / Accept Yours / Accept Theirs 选择。
- 支持 UTF-8（有/无 BOM）和带 BOM 的 UTF-16LE/BE；保存保持 Yours 的编码/BOM。CRLF/LF 提示取自 Yours；混合换行明确显示 `mixed`，不静默声明统一。
- Browser Mock 明确拒绝打开手工会话，不生成看似真实的正文。取消覆盖 load/recheck/save/resolve operation group；原子 replace 本身是短临界区，完成后仍检查取消与 digest，无法验证时返回 unknown/错误并要求刷新。
