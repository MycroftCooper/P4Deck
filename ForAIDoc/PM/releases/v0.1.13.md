# P4Deck 0.1.13

## 中文

新功能：
- 获取最新（Get Latest）显示真实进度：确认时把预览文件数下传，任务面板实时显示「x/y」与「已处理 N 个文件」，并每秒刷新「已用时」
- 设置 → 更新新增「查看更新日志」：内置 0.1.7–0.1.12 中英文发布记录，跟随界面语言
- 新增「打开产品主页 / 打开使用文档」按钮，链接由 host 侧白名单校验；链接被拒绝时当场提示
- 双击「工作区 / 待提交」里的文件，用系统默认程序打开；仅 depot、搁置或本地不存在时回退到应用内预览
- 标签页切换后恢复原来的滚动位置

改进与修复：
- 任务面板进度条可从 current/total 推导百分比；没有可用总数时保持不确定态，不再显示假的 0%
- 取消、超时或启动失败的任务立即从任务面板消失，不再残留
- 修复 Windows 长路径前缀（\\?\）泄漏到 p4 参数、已保存连接、界面标签、剪贴板和外部工具的问题；旧连接配置会在加载时自动修正
- 修复设置页左侧导航滚动后不吸顶
- 同步与列表更稳健：工作区根不再被 p4 where 预检误挡；目录列表的 resolve 预检超时会降级而不是整页失败
- 内部：产品页 / Wiki 地址收敛为单一清单，前端与 host 共用同一文件；发布说明支持中英双语并进入门禁

自动更新：从 0.1.7 起支持应用内自动升级；沿用同一签名密钥

## English

New:
- Get Latest shows real progress: the previewed file count travels with the confirmation, the task panel shows x/y and the processed-file count, and elapsed time ticks every second
- Settings → Updates gains a bundled changelog with 0.1.7–0.1.12 in Chinese and English, following the UI language
- New Open product page / Open wiki buttons; links are validated by the host allowlist and a rejected open is reported inline
- Double-clicking a file in the Workspace or Pending list opens it with the OS default app; depot-only, shelved or missing files fall back to the in-app preview
- Switching tabs restores the previous scroll position

Improved and fixed:
- The task panel's progress bar derives a percentage from current/total and stays indeterminate (no fake 0%) when there is no usable total
- Cancelled, timed-out or failed-to-start tasks leave the task panel immediately
- Fixed Windows long-path prefixes leaking into p4 arguments, saved connections, UI labels, the clipboard and external tools; legacy connection profiles are corrected on load
- Fixed the settings navigation not staying sticky after scrolling
- Sync and listings are more robust: the workspace root is no longer blocked by the p4 where preflight, and a directory-listing resolve timeout degrades instead of failing the page
- Internal: product/wiki URLs come from one shared manifest used by both renderer and host; release notes are bilingual and gated

Auto-update: in-app updates since 0.1.7; same signing key.
