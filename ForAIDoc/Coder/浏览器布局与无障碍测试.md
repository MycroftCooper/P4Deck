# 浏览器布局与无障碍测试

`pnpm test:browser` 使用真实 Chromium 浏览器在 390×844 viewport 下检查页面级横向溢出、关键控件可见/可聚焦，并对应用 Shell、Command Palette、Settings、Search、Pending、Dialog、Context Menu 与手工合并夹具运行 axe。

- Windows 默认复用已安装的 Microsoft Edge，不下载浏览器。
- 可用 `P4DECK_BROWSER_CHANNEL=chrome pnpm test:browser` 改用已安装 Chrome。
- 无系统 Chromium 时，先运行 `pnpm exec playwright install chromium`，再用 `P4DECK_BROWSER_CHANNEL=bundled pnpm test:browser`。依赖版本固定在 `package.json`，安装依赖时可设 `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1`。

浏览器门禁不能替代 NVDA/VoiceOver 与真实 Tauri 窗口验收；发布前仍需人工检查读屏朗读顺序、原生菜单和窗口缩放。

axe 扫描排除 Dockview 第三方 `.dv-tab` chrome（其内建关闭按钮嵌套在 ARIA tab 内）；所有实际 panel 内容仍扫描。该第三方结构与原生 tab/关闭按钮朗读需要在外部读屏验收中单列确认，不能因自动门禁绿色而宣称完成。
