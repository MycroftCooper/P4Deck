# P4Deck 0.1.15

## 中文

新功能：

- 新增「比较这两个文件」：在文件列表选中两个已入库文件后右键或按差异按钮，直接并排比较两个文件的最新版本；不足两个或缺少 Depot 修订号时会说明原因而不是发出请求
- 新增「比较所选修订」：文件历史页选中两个版本后，页面本身提供比较按钮（此前只能从右键菜单进入），在差异页也可以随时切换两侧的版本
- 搜索页新增右键菜单：搜索结果里的文件可以直接预览、看历史与修订图、比较版本、定位、复制各类路径；CL 结果可以打开详情、复制编号与描述、只刷新该类别；空白处可以复制查询条件、全选、清除选择和重新执行搜索。载荷证明不了的能力会说明原因而不是假装可用

改进与修复：

- 右键菜单只列当前能用的动作：此前折叠在「更多操作（待接入）」里的 90 多项灰菜单不再出现；重复或已明确不做的 17 项（例如「签出并用其他软件打开」「撤销已提交 CL」「导出日志」）已从菜单和验收清单里彻底删除，剩余 backlog 移入设计文档
- 服务器繁忙不再误判为断线：触发 Helix Core 命令并发上限时，状态栏显示「繁忙（并发上限）」并保持「可达」，只读查询自动重试两次（1 秒、3 秒退避），写操作不重试；繁忙输出只记为警告，不再弹诊断告警或刷红日志
- 响应慢更早可见：单次超时或单次响应超过 800 毫秒即显示为「响应较慢」，不必等满 5 个样本；后台刷新失败记为警告
- 修复 Diff 打开即「全部折叠」：WebView2 保留旧的表格行轨道会让所有行叠在同一条线上；现在每次渲染后按列内行数重建轨道，折叠策略不变
- 右键菜单移除「更改文件类型…」（F01、F02、F07、C04、C05 五个对象）；「还原未修改文件」改为直接可点击的顶级命令
- 修复切工作区时界面闪一下并丢失键盘焦点：连接引导页在重新校验期间不再把整个应用拆掉重建
- 修复待提交页失败被静默吞掉：搁置、移动、删除或刷新失败重新显示原因，不再只写进日志
- 修复窄窗口下待提交卡片：390 像素宽时描述不再被压成零宽、「更多」菜单不再被裁到卡片外点不到
- 修复窄窗口下 Diff 工具栏：上一个/下一个差异按钮不再被右侧控件遮住而点不到
- 修复窗口最小化/最大化/关闭按钮被读屏软件读成孤立按钮，恢复「窗口控制」分组名称
- 修复浏览器/演示模式里同一个文件第二次签出无声失败（Mock 返回缺少执行结果，前端误判为未确认）
- 内部：浏览器自动化测试从 81 个中 45 个失败修复到全绿，并接入门禁（提交前跑冒烟子集，交付前跑全量）
- 内部：Rust 侧六份各不相同的操作编号校验合并为一处；调用方传来的编号不合法时直接报错，不再静默换成新编号——此前那一次替换会让取消按钮打不中真正在跑的命令
- 内部：缓存时效改为从统一策略表读取，修订与修订之间的 Diff 按内容寻址保留 30 分钟，不再提前 5 分钟被清掉

自动更新：沿用同一签名密钥

## English

New:

- New Compare these two files: select two deposited files in a file list and compare their latest versions side by side from the context menu or the diff command; the bar explains what is missing instead of sending a request when the pair is not comparable
- New Compare selected revisions: selecting two versions on the History page offers the comparison on the page itself (it used to be reachable only from the row menu), and the diff page lets either side be changed at any time
- Search results have a context menu: a file result can be previewed, opened in history or the revision graph, compared, revealed and copied as any of its paths, a changelist result can open its details, copy its number and description or refresh just that category, and the empty area offers copying the query, selecting all, clearing the selection and running the search again. Anything the payload cannot prove says why instead of pretending to work

Improved and fixed:

- The context menu now lists only what works right now: the ninety-odd grey entries that used to be folded into More actions (pending) no longer appear; seventeen duplicate or deliberately out-of-scope entries (such as Check out and open with, Undo this changelist and the log exports) are gone from both the menu and the acceptance inventory, with the remaining backlog moved into the design documents
- A busy server is no longer mistaken for a connection failure: when the Helix Core command-concurrency cap is hit, the status bar shows Busy (concurrency cap) while staying Reachable, read-only queries retry twice with backoff, write operations never retry, and busy output is logged as a warning instead of raising a diagnostic alert or painting the log red
- Slow responses show up sooner: a single timeout or one response above 800 ms already reads as slow without waiting for five samples; background refresh failures log as warnings
- Fixed the diff opening entirely folded: WebView2 kept the stale table row tracks so every row stacked on one line; the tracks are now rebuilt after each render while the folding policy stays the same
- Change filetype is removed from the context menu (F01, F02, F07, C04 and C05); Revert unchanged files is now a top-level command that runs directly
- Fixed the whole window flashing and losing keyboard focus when switching workspace: the connection gate no longer tears the application down while it re-verifies
- Fixed failures being swallowed on the Pending page: a failed shelf, move, delete or refresh shows its reason again instead of only going to the log
- Fixed Pending cards in narrow windows: at 390 pixels the description no longer collapses to zero width and the more-actions menu is no longer clipped outside the card
- Fixed the Diff toolbar in narrow windows: the previous/next change buttons are no longer covered by the controls beside them
- Fixed the minimize, maximize and close buttons reading as unrelated buttons to screen readers; the window-controls group name is back
- Fixed the second checkout of the same file failing silently in the browser and demo builds (the mock did not return an execution result, so the frontend treated it as unconfirmed)
- Internal: the browser suite went from 45 of 81 failing to green and is now part of the gate (a smoke slice before freeze, the full suite before delivery)
- Internal: six slightly different operation-id validators in the Rust backend are now one; an id that does not meet the rule is rejected instead of being quietly replaced with a fresh one, which used to make Cancel miss the command that was actually running
- Internal: cache lifetimes come from the shared policy table, so a revision-to-revision diff keeps its declared thirty minutes instead of being evicted after five

Auto-update: same signing key.
