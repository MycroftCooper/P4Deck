# 命令速查

> 找命令只看这一页。所有命令都可直接 `node scripts/...`；`pnpm` 在本机要用 `pnpm.cmd`。

## 磁盘与缓存（2026-10-30 清理后：项目 ~20GB）

| 位置 | 当前 | 说明 |
|---|---:|---|
| `src-tauri/target` | 19.1GB | `debug/deps`（依赖）为主 + `release` 3.8GB；**incremental 已清 27GB** |
| `src-tauri/target-qa` | 0（已删，下次 QA 启动重建 ~5GB） | QA 独立 target，保证与普通 dev **可同时运行** |
| `.git/lfs` | 0.01GB | 已 prune 历史大文件，回收 4.2GB |
| TEMP `P4Deck-*` 候选 | 106 个 | 旧候选已归档文字证据并清理（回收 41.7GB） |
| TEMP `p4deck-shared/cargo-target` | 5.2GB | 跨候选共享 Rust 缓存 |

```powershell
pnpm wf:close                                          # 批次收尾：sync + 磁盘体检 + 建议命令（不删除）
node scripts/workflow/cache.mjs status                 # 2.2s，列出各区体积
node scripts/workflow/cache.mjs clean --incremental    # 清增量缓存（29GB→0；下次编译变慢）
node scripts/workflow/cache.mjs clean --release        # 清打包产物
node scripts/workflow/cache.mjs clean --lfs            # 只删未引用 LFS 对象（安全）
node scripts/workflow/cache.mjs clean --temp-candidates --days 2   # 清 2 天前候选（先 evidence --collect-temp）
```

**流程层面的修正**（三件事）：
1. **构建产物有生命周期**：每批收尾跑 `pnpm wf:close`，>10GB 的项当次清（`cache.mjs clean` 需显式执行，避免误删）。
2. **QA 保持独立 target**：`dev:desktop:qa` 用 `src-tauri/target-qa`，可与普通 dev 同时运行、互不阻塞；代价是多占约 5GB，收尾按需 `cache.mjs clean --target-qa`。
3. **候选可回收**：候选必须用 `cargo-candidate.cmd`（共享 target），创建时加 `env-candidate.mjs --copy-tsbuildinfo` 复制 tsc 增量；收尾时 `evidence --collect-temp` 再 `cache.mjs clean --temp-candidates`。旧 `target-qa` 仅作兼容，`cache.mjs clean --target-qa` 可清。
