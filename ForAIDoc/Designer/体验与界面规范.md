# P4Deck 体验与界面规范

> 文档编码：UTF-8  
> 当前状态：工作台 UI 第二版已落地（2026-09-29）

## 第二版工作台

- 配色采用石墨绿中性色与薄荷青绿强调色，浅色使用纸白背景；继续支持跟随系统和手动主题切换。
- 工作区采用资源浏览器、文件表、可折叠文件详情三栏布局，窄桌面窗口优先保留文件表。
- 文件页增加明确的标题、记录数与独立刷新入口；操作工具栏改为紧凑的图标加文字，按选中文件状态启用操作。
- 支持全部文件、本地修改、待更新三种本地筛选，舒适/紧凑行密度切换；这些交互不发起新的 P4 查询。
- 文件详情展示选中文件的状态、版本、CL 和 Depot 路径，提供 Diff 与历史入口；未选中时显示提示。
- 主文件表与左侧资源列表均使用虚拟滚动。文件详情复用已加载元数据，仅用户请求 Diff/历史时调用后端。
- Pending、Submitted、工具区同步使用统一的颜色、边框、字号和按钮样式。当前使用模拟数据，双平台原生表现与大数据性能仍需单独验收。

## 体验目标

P4Deck 不照搬官方 P4V。用户打开应用后应能迅速回答：

1. 当前连接的是哪个 Server、User 和 Workspace？
2. 当前有哪些本地修改？
3. 哪些文件需要同步或解决冲突？
4. 下一步最可能执行什么操作？

视觉关键词：现代、克制、专业、快速、可信赖。

## 信息架构

### 全局层

- 项目或连接名称、Server 和健康状态。
- 当前用户、通知、设置和命令面板。

### Workspace 层

- Workspace 切换器。
- Changes、Depot、History。
- Pending Changelists 和 Stream 信息。

### 内容层

- 页面标题和简短说明。
- 关键状态摘要。
- 可搜索、可筛选的主列表。
- 选择后的上下文操作。
- 后台任务和最近刷新时间。
- 默认关闭的 P4 命令行与 P4 Log 面板入口。

## MVP 主导航

- Changes：本地状态和 Changelist。
- Depot：服务器文件浏览。
- History：提交和文件历史。
- Workspace：显示当前用户拥有的工作区，支持搜索、刷新和详情查看。
- Settings：连接、工具、外观和快捷键。

Labels、Jobs、管理功能和高级 Integration 不进入首版主导航。

## Workspace Changes 页面

1. 顶栏：项目、连接状态、通知和用户。
2. 左栏：Workspace 切换和 Changelist。
3. 标题区：当前 Workspace 和 Submit 主按钮。
4. 状态摘要：Open Files、Incoming Files、Current Stream。
5. 文件列表：文件、Depot 路径、状态、修改时间和菜单。
6. 选择操作栏：Diff、Revert、移动到 Changelist。
7. 底栏：连接用户、刷新时间和 P4 CLI 版本。

## 交互规则

- 100 毫秒内完成的操作无需额外反馈。
- 100～500 毫秒使用局部 Loading。
- 超过 500 毫秒必须显示活动或进度。
- 长任务完成后使用非阻塞通知并提供结果入口。
- Revert 显示文件数量和修改丢失风险。
- 大范围 Sync 允许先预览。
- Submit 前显示描述、文件数量和校验问题。
- 破坏性按钮不得默认获得焦点。
- 错误需包含问题摘要、恢复动作和可展开的原始 P4 信息。
- P4 命令行默认关闭，支持底部停靠或独立窗口；打开后持续显示 Server/User/Workspace 上下文。
- P4 Log 默认关闭；任何新日志、Warning 或 Error 都不得自动展开、切换当前工具或抢夺焦点。
- 底部日志入口仅为未查看的新 Error 显示带可访问文字的红点；Warning/Info 不标红，用户打开日志后清除。

## Changelist 查询体验

- 提供关键词主搜索框和可组合的高级过滤器，而不是把所有条件永久铺开。
- 已启用条件显示为可单独移除的 Filter Chip，包括用户、状态、Client、路径、Stream 和时间范围。
- 提供“隐藏分支合并 CL”开关，并显示当前隐藏数量。
- “疑似合并”CL 使用文字和图标标记，不因默认过滤而静默消失。
- 支持保存和快速切换常用过滤器。
- 查询结果和 CL 文件列表必须虚拟化；滚动时筛选栏保持可见。

## 视觉方向

- 首版以深色主题为主，并为浅色主题保留 Design Token。
- 使用低对比背景层级，避免大面积纯黑。
- 主强调色建议偏黄绿，表达正常连接和可执行操作。
- 黄色表示 Modified/警告，绿色表示 Added/成功，红色只表示错误和破坏性操作。
- Changelist 可使用颜色标识，但颜色不能是唯一信息。
- 圆角和阴影保持克制，主要通过边框、间距和背景组织层级。
- 优先使用内置或系统字体，禁止运行时依赖网络字体。
- 文件列表提供 Comfortable 和 Compact 两种密度。

## 无障碍

- 核心操作全部支持键盘。
- 提供清晰的焦点状态。
- 对比度目标为 WCAG 2.2 AA。
- 状态同时使用图标或文字，不能只依赖颜色。
- 支持操作系统 Reduced Motion。
- 图标按钮必须有可访问名称和 Tooltip。
- 虚拟列表不能破坏屏幕阅读器的基本语义。

## 页面与状态

- Hash 路由：`#/files`、`#/pending`、`#/submitted`、`#/workspaces`、`#/history`、`#/streams`、`#/diff`、`#/revgraph`、`#/terminal`、`#/p4log`。Streams 恢复为独立分支流列表，不再重定向 Workspace。
- Diff / Rev Graph 是独立可停靠页签，可从“窗口”菜单打开，也可通过文件工具栏或右键菜单带入目标文件；重复打开时优先复用同目标或未锁定实例，锁定实例不会被改写；也可主动新建实例。支持手动输入路径、刷新、加载失败与空状态，按连接和路径缓存 30 秒。
- Diff 使用虚拟行列表和增删高亮，显示后端返回的左右版本标签，二进制内容给出提示。Rev Graph 支持缩放、节点选择、版本/分支/合并/复制连线，避免每条边重复遍历节点。
- 对照 P4V 窗口清单保留 Depot Tree、Workspace Tree、History、Pending Changelists、Submitted Changelists、Workspaces、Streams、Log；另保留文件页和命令行。Branch Mappings、Labels、Jobs、Stream Graph、Dashboard 不在本次范围。
- 左侧 Depot/Workspace 树与底部命令行/日志快捷工具区固定保留，只能折叠；Terminal/P4 Log 另有可关闭、分屏和弹出的全局单实例页签。所有主页签关闭后仍可通过活动栏、命令面板或应用 View 菜单恢复。
- 主内容使用 Dockview：拖动页签重排，拖到内容区边缘左右/上下分屏，拖动分隔线调整比例。分组右侧提供左右分屏、上下分屏、弹出独立窗口按钮。布局在本地保存。
- 页签拖出窗口边界可弹出；浏览器使用同源弹出窗口，桌面端使用受限的 Tauri 原生窗口。原生独立窗口关闭后页签回到主窗口；主窗口重启时恢复尚未归还的页签。浏览器可能要求允许弹出窗口。
- 移除空的全局右侧栏和文件页默认详情栏；有实际选中数据的 Workspace、Streams、History 等页面继续按需展示详情。
- 左侧折叠入口固定在顶部，底部箭头折叠工具区。折叠不会取消后台操作。
- 已验证浏览器分屏和弹出路径；原生窗口与跨平台拖出行为仍需 Windows/macOS 实机验收。原生子窗口会重建页面，暂不支持将子窗口页签跨窗口拖回，关闭子窗口可归还页签。
- History 复用文件历史接口，支持选中文件的 Depot 路径或手动输入路径；Streams 使用后台只读查询。两页采用虚拟列表、按连接与查询条件隔离的 60 秒缓存及手动刷新。
- Workspace 页签按当前有效 P4 用户查询归属，显示名称、Owner、Host、Root 和更新时间；选择后显示 Stream、访问时间和描述。当前工作区带标记，选择列表行仅查看详情。
- 使用 `p4 clients --me -t` 后台只读查询，结构化解析在 Rust 完成。列表虚拟化，前端按连接上下文缓存 60 秒、合并并发请求，手动刷新使缓存失效；搜索在本地完成。参考 [P4 clients 官方文档](https://help.perforce.com/helix-core/server-apps/cmdref/current/Content/CmdRef/p4_clients.html)。
- 左侧 Workspace/Depot 浏览器跨页面保留，宽度、展开节点、选择和过滤状态持久化。
- 主题支持 system/light/dark，使用语义变量；首次跟随系统，用户选择持久化。
- 地址栏默认显示选中文件相对路径，接受相对、本地绝对和 Depot 路径；成功定位必须展开、选中并滚动到目标。
- 底部工具条永久可见，一个箭头负责折叠/展开；Tab 仅叫“命令行”“日志”。

## 文件状态—可用操作矩阵

| 状态 | 获取版本 | Checkout | Add | Delete | Revert | Diff | History/Graph |
|---|---:|---:|---:|---:|---:|---:|---:|
| Controlled | 是 | 是 | 否 | 是 | 否 | 是 | 是 |
| Opened Edit | 风险提示 | 否 | 否 | 是 | 是 | 是 | 是 |
| Untracked | 否 | 否 | 是 | 废纸篓 | 否 | 否 | 否 |
| Opened Add | 否 | 否 | 否 | 确认 | 是 | 本地内容 | 否 |
| Opened Delete | 否 | 否 | 否 | 否 | 是 | 删除前版本 | 是 |
| Out-of-date | 是 | 风险提示 | 否 | 风险提示 | 依状态 | 是 | 是 |
| Conflicted | 禁止覆盖 | 否 | 否 | 否 | 确认 | 三方入口 | 是 |

工具栏与右键菜单必须按照此矩阵给出相同的启用状态和禁用原因。删除始终确认；P4 操作失败不得继续删除本地文件。

## 参考界面取舍

### 全局设置与文件页签实例

- 顶栏齿轮、连接入口和“窗口 → 设置”打开同一个设置页签；连接参数显式保存，主题、语言、文件列表密度、侧栏宽度、列表字号、减少动画即时生效并持久化。
- 连接参数保存到应用数据目录，所有后续 P4 查询使用新上下文。已有操作保留原上下文；保存不代表测试成功。密码、票据内容不进入设置存储，浏览器演示模式不连接真实服务器。
- Files、Pending、Submitted、Workspace、Streams、设置是全局单实例页签。History、Diff、Rev Graph 是可多实例的文件页签，实例 ID 与页面类型分开保存。
- 文件页签工具条显示目标与锁定按钮。未锁定实例跟随文件选择；锁定实例保持原目标且禁用路径编辑。解锁后恢复跟随后续选择。
- 打开文件工具时优先复用同目标实例，其次复用未锁定实例；全部锁定且目标不同时创建新实例。页内“新页签”可主动多开；目标与锁定状态随布局恢复，关闭重开遵循同样规则。
- 桌面独立窗口通过主窗口分配新页签以保持全局唯一；关闭独立窗口时恢复原实例。跨原生窗口直接拖回仍沿用现有能力限制。

- 采用老版 P4V 的 Workspace/Depot 双浏览器、高密度文件表、对象工具栏、Pending CL 树和上下文菜单。
- 采用 uGit 的现代顶部对象导航、清晰留白、主题系统、弱边框和统一图标。
- 不复制 P4V 的多层碎片 Tab、低对比度和过度拥挤；不把 Git 的 Stage/Branch 语义套到 P4 CL/Stream。

### 文件预览（首版）

- 新增“文件预览”多实例页签，继承目标锁定、跟随选择、布局持久化、分屏和弹出。窗口菜单、文件工具栏、右键菜单或双击文件进入。
- 读取当前工作区本地副本（含未跟踪文件）；Depot 路径只用于定位已同步的本地副本，不自动下载服务器内容。后台线程执行有界读取，限制路径不得逃出工作目录。
- 文本只读，支持 UTF-8 与带 BOM 的 UTF-16，最大 2 MiB，虚拟行显示；单行超过 4000 字符截断显示并提示，不渲染 HTML/Markdown。
- 图片支持 PNG/JPEG/GIF/WebP，最大 8 MiB 且不超过 2000 万像素，支持适应窗口及缩放。SVG 按文本处理。图片损坏、格式不支持、文件未同步和超限均显示明确提示。
- 选择跟随防抖 150ms；相同目标请求去重，缓存新鲜期 3 秒、最多保留三个已完成结果，并可手动刷新。浏览器模拟内容明确标识。
