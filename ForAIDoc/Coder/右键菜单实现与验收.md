# 右键菜单实现与验收

更新时间：2026-09-29。状态：本轮右键菜单 UI 与统一框架实现、验收完成；完整 P4 工作流接入不在本轮完成声明内。

范围依据：[对象 × 菜单项总表](../Designer/右键菜单对象与菜单项总表.md)。本次实现全部菜单 UI，不将未接通的 P4 工作流伪装成可执行功能。

逐项记录见 [492 项 UI 验收台账](右键菜单UI逐项验收台账.md)。清单中的高级动作集中在“更多操作（待接入）”；当前不能执行的动作明确禁用并给出原因。表头列配置等尚无控制器的能力也不假装可切换。

## 架构

| 层 | 文件 / 模块 | 职责 |
| --- | --- | --- |
| 清单 | `src/app/context-menu/catalog.ts` | 对象 ID、叶子项 ID、文案、实施阶段；与设计总表逐项比对 |
| 菜单模型 | `model.ts` | 合并能力绑定、禁用原因、动态子菜单、危险项、隐藏单例入口；不访问后端 |
| 交互容器 | `ContextMenu.tsx` | 单实例 Portal、定位、键盘、子菜单、焦点恢复、关闭生命周期、异步结果防串线、执行错误反馈 |
| 业务适配 | `useFileMenu.ts`、`useDirectoryMenu.ts`、`useContentMenu.ts` | 文件/目录/查看内容共享动作和能力判断；执行使用目标快照 |
| 列表选择 | `useRecordSelection.ts` | 稳定 ID、多选、范围选择、右键选择语义、键盘选择 |
| 应用能力 | `environment.ts`、CommandContext、commandPolicy | 导航、页签、偏好设置和已有工具栏命令；不在每个页面重复写 P4 命令 |
| 特殊界面 | `FullTextSelection.tsx`、TaskList、TabMenu | 虚拟文本全选、具体任务操作、Dockview 页签/分组操作 |
| 验收工具 | `MenuAuditPage.tsx` | 仅开发环境 `?menu-audit`；遍历菜单并绑定无副作用的验收回调，不模拟业务成功 |

菜单打开先使用已有数据；异步能力结果带请求序号，旧结果不能覆盖新菜单。文件状态查询复用缓存，系统打开能力独立于 P4 状态。关闭、连接/页面切换、对象移除后，不保留旧菜单。

## 本轮修正

- 修订图 Shift+F10 与鼠标右键使用同一菜单，不再把多节点退回单节点。
- Pending 文件和日志行补充键盘选择；嵌套按钮不触发行选择。
- 页签栏“关闭本组”捕获所在组和页签快照，增加组操作区键盘入口。
- 异步文件操作完成后的焦点刷新使用执行目标身份，不使用打开菜单之前的工具栏目标。
- 动态目标组子菜单只显示父菜单名称，不显示清单中的占位文字。
