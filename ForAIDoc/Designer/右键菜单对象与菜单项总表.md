## 阅读与追踪规则

- `☐` 表示该对象下此菜单项尚未完成统一实现与验收；即使已有工具栏按钮或简易菜单也不算完成。通过后改为 `☑`。目录一致性测试同时识别两种标记，状态变化不改变稳定 ID。
- 每行菜单项依书写顺序编号，例如 `F01-01` 是单个工作文件的“文件预览”；后续追加项放末尾，删除项保留编号注明取消，避免任务 ID 漂移。
- “首期”和“后续”是建议批次，不是删减功能；两列全部保留在清单中。后续列编号接首期列继续，顺序为先首期后后续。
- 2026-10-09 P1 增量：F01/F02/F07/C04/C05 的“锁定/解锁”虽保留原编号和原列位置，现已接 BE-011 生产预检工作流，不再是占位；实际可用性由 opened 状态、锁 owner、权限和完整文件集预检决定。
- 2026-10-09 P1 Swarm 增量：C02-13、C03-07、C06-07、C09-08、C10-13、V01-12、V04-07、V08-05 的“在 Swarm 中打开”已完成；保留原编号和原列位置，缺配置或不支持的目标会引导设置或置灰说明。
- `复制 › 本地路径` 表示子菜单中的真实叶子项；子菜单容器不单独算一个动作。`…` 表示后续有参数选择/确认。
- 下列菜单项是候选全集，不要求所有状态都显示全部项：无关项隐藏，相关但暂不可执行的项置灰并解释原因。权限和状态仍需执行前校验。
- 不采用“同上”省略关键对象的菜单；不同来源即使共用组件，也要分别验收。

## 尚未纳入实施、必须明确记录的取舍

| 参考功能 | 当前决定（待确认） |
| --- | --- |
| Time-lapse / 逐行时间演化 | 暂缓，不用普通 History 冒充 |
| Bookmark / 收藏 | 暂缓，需先设计收藏入口与持久化 |
| 本地物理删除 / 清理目录 | 首轮不做；与 P4 标记删除、移除受控副本严格区分 |
| 提交所选文件 | 首轮不做，只提供提交整个 CL；需要独立的部分提交流程后再加 |
| 目录聚合历史 / 目录差异 | 暂缓，不能调用单文件接口代替 |
| 多选批量预览 / 系统打开 | 首轮不做，避免一次打开大量页签或系统窗口 |
| Stream 删除、强制删除 Workspace/CL、管理员操作 | 不列入当前普通用户菜单；后续单独设计权限与风险流程 |
