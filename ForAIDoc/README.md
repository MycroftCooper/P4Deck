## 项目简介

前端下一批执行清单：[前端操作流程 TODO](PM/前端操作流程TODO.md)。范围为对话框和操作流程 UI，不包含后端服务实现。

P4Deck 是一个面向 Windows 和 macOS 的现代 Helix Core 桌面客户端。它专注于日常 Workspace、文件状态、Changelist、Diff、Sync 和 Submit 工作流，目标是比传统 P4V 更清晰、更流畅、更安全。

项目以六项核心目标约束所有产品和技术决策：前端与 P4 操作彻底解耦、大数据量虚拟化、本地缓存与服务器降载、现代 UI、低资源占用，以及 Windows/macOS 双平台一致支持。详细定义与质量指标见 [项目立项书](PM/项目立项书.md#核心目标)。

项目不可妥协的首版能力见 [P4Deck 核心功能基线](PM/核心功能基线.md)：按需 P4 命令行、自动错误日志、完整 CL/Shelf 工作流、强制虚拟列表以及 CL 组合查询与合并降噪。

当前代码落地范围、验证方式和后续深化项见 [核心功能实现说明](Coder/核心功能实现说明.md)。
