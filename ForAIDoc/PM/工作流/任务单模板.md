# 任务单模板（≤200 字，固定 9 行）

> 现在**不需要手写**：`node scripts/workflow/state.mjs task <ID> --for <ROLE> --message` 直接生成同格式任务单。
> 本文件只用于人工补写或解释格式。

## 模板

```
任务 <ID> ｜ <type: bug|feature|refactor> ｜ <P0|P1|P2> ｜ <模块>
范围 <一句话，只说这次要改什么>
写域 <具体路径或 glob；跨角色时写"FE:… / BE:…">
依赖 <任务 ID 或"无"；写"无"就表示可以立刻开工>
退出 <可判定的完成条件：产出 + 必须跑过的命令>
禁做 <本片特别禁止的事；通用禁区不重复>
门禁 <本片要跑的命令，例如 ci-fast --files … --role FE>
证据 <manifest/回执/QA json 的路径>
预算 ≤<N> 轮；超限停笔报告
```

## 填写规则

1. **只写本次**。"背景/历史/上一批为什么失败"不进任务单，去 `state.json` 对应 ID 的 `note` 与 `evidence` 查。
2. **退出条件必须可执行**：写"`pnpm ci:fast` 通过 + 新增 2 个 adapter 测试"，不写"完成适配"。
3. **禁做只写增量**：通用禁区（生产 P4、真实工具、打包发布）已在角色合同里，不重复。
4. 一行一件事，不用小标题、不用表格、不贴截图。

## 示例 A（FE 纯适配切片）

```
任务 FE-S2-PURE-SHELF ｜ feature ｜ P1 ｜ ACTION-R01 / 阶段2a
范围 在冻结 S1A 内核上新增 SHELF 删除的纯投影 adapter，不接业务入口
写域 src/features/changelists/action/** + 相邻 *.test.tsx
依赖 S1A-frozen
退出 adapter 可运行；覆盖确认前零变化/接受后局部隐藏/重叠冲突/unknown 不重试；ci:fast 通过
禁做 不改 S1A 冻结文件；不新增 IPC；不接 DeleteShelfDialog
证据 evidence/fe-s2-pure-shelf-handoff.json
预算 ≤10 轮
```

## 示例 B（BE 契约切片）

```
任务 BE-S1B ｜ feature ｜ P1 ｜ ACTION-R01 / 阶段1
范围 MOVE 首权威检查至最终持久结果整段 MutationGuard；Terminal 读分类收紧；unknown 显式解除
写域 src-tauri/src/app/**、src-tauri/src/ipc/**
依赖 BE-S1A
退出 跨窗 MOVE 与 Terminal 全阶段互斥；排队取消零写；解除活动任务被拒；cargo check --offline --locked --lib 通过
禁做 不重写后继动作结果；不另建锁总线
证据 evidence/be-s1b-handoff.json
预算 ≤12 轮
```

## 示例 C（Apply 任务）

```
任务 CON06-APPLY ｜ feature ｜ P1 ｜ 阶段收口
范围 把已过 QA 的 CON06 候选按 manifest 应用到本地原树
写域 原树（仅 manifest 列出的文件）
依赖 CON06-QA、用户确认 dev 已关闭
退出 verify PASS → dry-run 计划复核 → apply 回执 originalApplied=true
禁做 不夹带未验切片；漂移即停，不覆盖用户改动
证据 artifacts/workflow/apply-<时间戳>.json + post-apply-verify-*.json
预算 ≤4 轮
```

## 反面示例（旧写法，禁止）

> "本条覆盖此前 CON06 独立应用及 PKG02 最后搁置安排…… 原树保持当前 JOIN04：停止 CON06 单独 Apply/关 dev 催促，不提前合入 ACTION 任一阶段……"（约 400 字，且必须读完整段才知道要做什么）
