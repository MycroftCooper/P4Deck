# P4Deck 开发路线图

> 文档编码：UTF-8

## 阶段 0：项目启动

- 完成立项、MVP 和技术选型。
- 建立 Tauri、React、TypeScript、Rust 工程。
- 建立 Windows/macOS 环境检查、测试目录和文档规范。
- 确定基础 UI 方向。

退出条件：项目可在干净的 Windows 和 macOS CI 中完成构建。

## 阶段 1：最小完整链路（1～2 周）

- P4 CLI 自动发现和手动配置。
- `P4Client` 接口、命令策略、错误分类和 Fixture 测试。
- 连接检测、SSL trust、登录状态和退出登录。
- Workspace 列表、验证后切换和基本信息；后端版本化多连接 profile/旧配置迁移已完成，完整设置页管理 UI 待接线。
- 本地设置和缓存结构。
- 建立 P4 命令执行会话、命令行窗口协议和脱敏日志事件模型。
- 建立默认关闭的 P4 Log 面板，实现 Warning/Error 自动展开策略。

退出条件：用户无需终端即可连接服务器并进入 Workspace。

## 阶段 2：日常 Workspace 工作流（2～4 周）

- 汇总 Opened、Reconcile 和 Out-of-date 状态。
- 增量数据流；所有列表第一次实现即使用虚拟化，禁止全量 DOM 过渡方案。
- 带预览和进度的 Sync。
- Edit、Add、Delete、单文件安全 Rename/Move 和 Revert；目录/跨 Workspace/覆盖/Windows 仅大小写 rename 延后。
- 文件 Lock/Unlock 与 `+l` 独占状态已通过完整快照 token、mutation lane 复检、逐文件验证和双用户/双 Client localhost E2E 接入；force unlock 不在产品范围，原生 UI/macOS 待验。
- 文本 Diff 和文件历史。

退出条件：开发者能够安全完成日常文件操作。

## 阶段 3：Changelist 工作流（2～3 周）

- Pending Changelist 的创建、编辑和删除。
- 文件在 Changelist 之间移动。
- Shelve、更新/删除 Shelf、Unshelve 和 Shelf 内容预览。
- CL 组合查询：关键词、状态、用户、Client、路径、Stream 和时间段。
- 分支合并/集成 CL 的后端可靠识别、详情缓存、前端按需详情、疑似/未知标记和仅隐藏 reliable 的升级机制已完成；过滤器保存和原生 UI 验收待完成。
- Submit 前校验、进度和错误恢复。
- Submitted History、操作记录、离线和 ticket 过期状态。

退出条件：私有 Alpha 用户可以完成修改到提交的完整闭环。

## 阶段 4：Beta 质量（3～5 周）

- Shelf 跨 Workspace 完善、Resolve 和基础 Stream 切换。
- 基础 Swarm 链接已完成：profile 级安全 URL、CL/Shelf/File/Revision 官方路由、统一 action 与 native 最终 allowlist；Swarm API/登录/评论/Review 创建不在此项范围。
- 无障碍、诊断导出和本地化基础。
- macOS/Windows 签名安装包和自动更新设计。
- 前后端本机性能基准已建立；兼容矩阵与固定设备认证仍待完成。

退出条件：核心指标达标且不存在 P0 安全或无障碍问题。

## 第一批研发任务

1. 已建立仅手工触发、不发布的 macOS、Windows、Linux CI 配置样板；项目没有 remote，远端 runner 尚未执行。
2. 已配置本地统一入口及样板中的前端 Build/Test 和 Rust fmt/clippy/check/test；远端结果仍待未来验证。
3. 将具体 `P4Client` 改为可替换接口。
4. 实现命令白名单、超时、取消和输出上限。
5. 实现 `p4 -V`、`p4 info` 领域模型和 Fixture 测试。
6. 完成连接配置结构和登录安全设计。
7. 已建立前端 50,000/100,000 行与后端 parser/IPC/cache/cursor 10,000/50,000/100,000 本机自动性能报告；固定 Windows/macOS 设备、原生滚动/FPS、精确峰值内存和多 P4 版本仍待验收。
8. 设计 P4 命令行与 P4 Log 的 Tauri 多窗口/停靠面板技术验证。
9. 定义 CL 查询模型和分支合并 CL 识别规则。
## 当前对象工作台批次

1. 对象模型、操作矩阵、Pending/Submitted/Shelf 工作流和工作台线框。
2. 主题、Workspace/Depot、对象页签、地址定位和折叠工具区。
3. 文件工具栏/右键菜单与 Mock Backend。
4. Rust Workspace/Depot/File Repository 和真实 P4 命令。
5. Diff、History、Revision Graph、Pending 拖放及 Shelf 风险流程。
6. 本地 p4d E2E、前端大列表与 BE-009b 后端本机自动基准已完成；macOS/Windows 固定设备性能、多版本/Unicode 矩阵与原生冒烟待完成。
